# Branding assets

`pchs-logo-placeholder.svg` is a temporary stand-in mark (not the official
seal) used until the real logo file is added to the repository.

To install the official logo:

1. Add the official PCHS seal file as `pchs-logo.png` (and ideally a
   transparent-background version) in this folder.
2. Update `src/lib/config.ts` → `siteConfig.logo` to point at the new file.
3. Remove `pchs-logo-placeholder.svg` once the real asset is in place.

Do not distort, recolor, or crop the official seal.
